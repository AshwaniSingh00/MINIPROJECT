# Blood Donation Management System

The **Blood Donation Management System** is a full-stack web application designed to efficiently manage blood donors, blood requests, and donation records.  
The project helps streamline communication between donors and recipients and reduces manual data handling.

---

## 🚀 Features
- Donor registration and management
- Blood request management
- View available donors by blood group
- Responsive and user-friendly UI built with React
- RESTful APIs for backend operations
- Clean separation of frontend and backend
